## 3. Stack

Plain static HTML generated by a small Python build script, served by a
Cloudflare Worker using Workers Static Assets. No framework, no bundler, no npm
runtime dependency — `wrangler` is the only dev dependency.

```
src/layout.html         shared <head>, header, footer, floating WhatsApp button
src/partials/           header.html, footer.html, cta.html, form.html
src/pages/**/*.html     one file per page: front matter + body (goes inside <main>)
src/worker.js           POST /api/lead → email via Resend; everything else → assets
build.py                src/pages → public/**/*.html + public/sitemap.xml
public/                 deployed directory; generated HTML IS committed
public/_redirects       301 map (41 rules)
public/_headers         security headers + asset caching
wrangler.jsonc          Workers config
```

**Rule: edit `src/`, never the generated HTML in `public/`.** The exceptions are
`public/assets/*`, `_redirects`, `_headers`, `robots.txt`, which are hand-written
static files.

Clean URLs come from `html_handling: "auto-trailing-slash"` — `public/about.html`
serves at `/about`, `public/stories/index.html` at `/stories/`.

**Front matter keys:** `title`, `description`, `priority`, `body_class`,
`og_type`, `image`, `updated`, `noindex`.
**Body markers:** `<!--CTA-->` and `<!--FORM-->` expand to the shared partials.

**Commands:**

```bash
python3 build.py     # regenerate public/ from src/
npm run dev          # build + wrangler dev on http://localhost:4599
npm run deploy       # build + wrangler deploy
```

## 5. Design system: "Lagoon"

Chosen by the owner from three directions presented on a Claude design canvas
(Tide — dark ink with bright cyan; **Lagoon — light and airy, cyan-led**; Mist —
muted grey-cyan minimal).

**Colors**

| Token | Value | Use |
| --- | --- | --- |
| `--teal-900` / ink | `#10333B` | Dark sections, primary buttons, footer |
| `--teal-500` | `#12B5CB` | Lead cyan, accents, step numbers |
| `--teal-600` | `#0E9DB2` | Cyan for text and links |
| `--teal-50` | `#E6F7F9` | Hero and trust-strip ground |
| `--paper` | `#FBFDFD` | Page background |
| `--line` / `--line-2` | `#D9EEF1` / `#B9E3E9` | Borders |
| `--wa` | `#25D366` | WhatsApp green, unchanged |

**Type:** Suez One for display (single weight — all headings are `font-weight:400`,
enforced with an `!important` rule), Rubik for body. Loaded from Google Fonts.
Heebo and David Libre from the first rebuild are gone.

**Shapes:** 14px button radius (not pills), 22px card radius, chip-style eyebrows
with a border, portrait as a white-framed card rotated −2°, trust strip as
separate cards, solid dark bands for how-it-works, footer and article CTAs.

Asset versioning is manual: bump `?v=N` on the CSS and JS links in
`src/layout.html` when either changes, because `_headers` caches `/assets/*` for
7 days.

## 6. Forms and the lead pipeline

Two forms share `src/partials/form.html` and the intake page's own markup; both
POST JSON to `/api/lead`.

**Worker** (`src/worker.js`) validates, rejects a honeypot field silently with a
fake 200, rate-limits 5 requests/minute per IP, then sends the submission by
email through **Resend** to `LEAD_TO` (default `micsam4@gmail.com`), with the
sender's address as reply-to and a WhatsApp deep link to the submitter in the
body.

**Front end** (`public/assets/site.js`) posts the form, shows a success panel on
200, and on any failure shows an error with a **one-tap WhatsApp link carrying
the same content**. No lead is ever lost to a backend outage.

**Custom select.** The macOS native `<select>` popup ignores `color-scheme` and
rendered dark against the light form, so the JS replaces each select in
`.field` with an ARIA listbox (button + `role="listbox"` + `role="option"`,
arrow keys, Enter, Escape, Home/End, click-outside to close). The real `<select>`
stays in the DOM hidden, so the value still submits and a no-JS visitor gets the
native control.

**Secrets:**

```bash
npx wrangler secret put RESEND_API_KEY   # done
npx wrangler secret put LEAD_FROM        # not done — needs a verified domain
```

- Unique Hebrew `<title>` and meta description per page, canonical, Open Graph,
  Twitter card.

  `BreadcrumbList` on each service page; `FAQPage` on the FAQ; `HowTo` on

- Target intent clusters: מטפלת זוגית אונליין, טיפול זוגי אונליין, טיפול משפחתי

  הדרכת הורים אונליין, טיפול אישי אונליין.

## 8. What was deliberately not done

Compliance and honesty constraints applied throughout:

- **No invented reviews or testimonials.** The thank-you letters are real, shown
  without star ratings (the first rebuild had fake 5-star graphics on them).
- **No fake scarcity**, no "limited spots", no countdown.
- **No medical overclaims.** Research is described as "studies report" with no
  specific success-rate promise attached to her practice.
- **No clinic address** as the location story.
- **Zoom is never named** — Google Meet is the real tool.
- The old Google Form intake was replaced with a native page, not kept.

## 11. Gotchas for the next session

- `build.py` **deletes every `.html` under `public/` before regenerating**, so a
  hand-edited file there is lost. Always edit `src/`.
- Suez One has one weight. Any new heading needs `font-weight:400`; the global
  rule covers the known selectors but a new class will not be in that list.
- Bump the `?v=N` query on CSS and JS in `src/layout.html` after changing either,
  or the 7-day asset cache serves stale files.
- `wrangler dev` reads `public/`, so run `python3 build.py` after editing `src/`.
- The Worker returns 503 when `RESEND_API_KEY` is absent and 502 when Resend
  rejects the send; both trigger the same WhatsApp fallback in the UI.
- Deploying with `npx wrangler deploy` publishes to the workers.dev preview URL,
  not to the live domain — that is still safe to run at any time.
